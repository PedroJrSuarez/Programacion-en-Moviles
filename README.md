### Estructura del Repositorio

El proyecto se organiza en dos ramas principales, cubriendo las **16 semanas** del curso:

* `sin-ia` — Laboratorios desarrollados de forma tradicional (sin asistencia de IA).
* `con-ia` — Versiones mejoradas e impulsadas con asistencia de Inteligencia Artificial.
